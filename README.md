# IndexedDB v1–v5 迁移演示

一个无构建的静态应用，用 Web Worker 执行 IndexedDB 迁移，主线程更新 DOM，并用 Canvas 展示分段迁移进度。

## 运行

由于使用 Web Worker，请通过 HTTP 服务打开，不要直接双击 HTML：

```bash
python3 -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。

## 版本规划

- **v1**：创建 `users`、`appMeta`，生成旧格式用户数据。
- **v2**：创建 `posts`，为旧用户补 `handle`、`email`，新增 `users.by_handle` 索引，并为每个用户生成介绍帖。
- **v3**：创建 `comments`，为帖子生成 `excerpt`，并为每个帖子生成欢迎评论。
- **v4**：创建 `attachments`，为评论生成 `snippet`，并为每个帖子生成封面附件。
- **v5**：创建 `auditLogs`，把附件数字大小转换为 `sizeLabel`，并为附件生成审计记录。

## 异常与验收路径

- **成功迁移**：点击“生成 v1 旧数据”，目标选 v5，点击“开始迁移”。
- **迁移中断可续**：开启慢速转换，迁移中点击“中断 Worker”，再次点击“开始迁移”会从已提交版本继续。
- **失败可回滚**：失败注入选择 v2–v5，当前版本事务中止后数据保留在上一版本；取消注入即可续迁。
- **版本回退提示**：迁移到高版本后，将目标切到低版本并开始，会阻止 IndexedDB 降级并提示，数据不改动。
- **旧数据兼容**：v1 种子只含 `id/name/createdAt`，后续版本逐级补字段和关联数据。
- **数据库被占用**：点击“模拟数据库被占用”后再迁移，会收到 `blocked` 提示；点击“释放旧连接”继续。
- **隐私模式降级**：IndexedDB 探测失败或访问 `?mode=memory` 时使用内存数据库，应用不崩溃但刷新不保留。
- **浏览器差异**：包含游标 `getAll` 回退、Worker 不可用回退、Canvas 2D 不可用文本回退，以及空库和受限 IndexedDB 处理。
- **进度可视化**：Canvas 分 5 段显示每版 20% 的进度；DOM 进度条和百分比同步。
